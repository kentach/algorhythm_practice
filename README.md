## Question1

下記の関数を書いてください。

Aは長さ1以上100以下の文字列である。Aが引数として与えられたとき、3の倍数または3が含まれる順番（
例：3,6,9,12,13,15,18,21,23,24...）における文字列をつなげた文字列を返り値にする関数を書いてください。

- 入力： "abcdefghi"
  - 3の倍数または3が含まれる順番：3, 6, 9
  - 該当する文字："c", "f", "i"
  - 出力："cfi"
- 入力： "123456789"
  - 3の倍数または3が含まれる順番：3, 6, 9
  - 該当する文字："3", "6", "9"
  - 出力："369"
- 入力： "abcdefghij"
  - 3の倍数または3が含まれる順番：3, 6, 9
  - 該当する文字："c", "f", "i"
  - 出力："cfi"
- 入力： "abcdefghijklmnopqrstuvwxyz"
  - 3の倍数または3が含まれる順番：3, 6, 9, 12, 13, 15, 18, 21, 23, 24, 27
  - 該当する文字："c", "f", "i", "l", "m", "o", "r", "u", "w", "x"
  - 出力："cfilmoruwx"
- 入力： "0123456789"
  - 3の倍数または3が含まれる順番：3, 6, 9
  - 該当する文字："2", "5", "8"
  - 出力："258"

## Question４

  文字列 `S` が入力されます。
  文字列 `S` の中で**最も多く出現する文字**を1文字出力してください。
  同じ回数で複数存在する場合は、**最初に登場した文字**を出力してください。

例
- 入力：`"aabcccbb"`
  - 出現回数
    - `"a"`：2回
    - `"b"`：3回
    - `"c"`：3回
  - `"b"` と `"c"` はどちらも3回出現しますが、`"b"` の方が先に登場するため
  - 出力：`"b"`

- 入力：`"abc"`
  - 出現回数
    - `"a"`：1回
    - `"b"`：1回
    - `"c"`：1回
  - すべて同じ回数なので、最初に登場した `"a"` を出力
  - 出力：`"a"`

- 入力：`"zzzzabc"`
  - 出現回数
    - `"z"`：4回
    - `"a"`：1回
    - `"b"`：1回
    - `"c"`：1回
  - 出力：`"z"`

- 入力：`"aabb"`
  - 出現回数
    - `"a"`：2回
    - `"b"`：2回
  - 同じ回数なので最初に登場した `"a"` を出力
  - 出力：`"a"`
